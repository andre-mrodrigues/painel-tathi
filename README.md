# Painel Tathi Deândhela · AW

Quadro de demandas do projeto Gigantes no Palco (AW Corp × Instituto Deândhela) e formulário público de pedidos.

- `index.html`: o quadro. Todos veem; só o admin (login por e-mail e senha) edita.
- `solicitar.html`: formulário de nova demanda; o pedido entra na coluna Solicitações.
- Os dados ficam no Supabase e atualizam ao vivo para quem está com a página aberta. Este repositório só guarda o site.

Publicado na Netlify (site `painel-tathi-aw`). Cada push na branch `main` publica sozinho.
